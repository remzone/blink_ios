# Xray geodata

Bundled geoip.dat and geosite.dat are copied unchanged from the official Xray
archive used by this project's panel deployment. They enable client JSON rules
without downloading or substituting routing lists at runtime.

Source: https://github.com/XTLS/Xray-core/releases

geosite.dat SHA256: `ef725a08ba804effd5b5b6e747c8c28eabc54ed068d786d7366d067d2e1a3849`

The distribution's complete LICENSE is preserved alongside these data files.
Updates must replace both clients' copies and this manifest together.
