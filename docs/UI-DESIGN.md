# Дизайн клиента iOS / iPadOS

Apple TV — только визуальный референс. Отдельный tvOS target, интерфейс или VPN-клиент не создавались.

## Активные экраны

BlinkTheme объединяет цвета, фон, карточки, типографику, SF Symbols и компоненты состояний. Главная HomeView показывает реальный статус, кольцо подключения и карточки переходов. Выбор сервера открывает профили; отключение вызывает существующий контроллер. Визуальное подключение не симулируется.

UniversalProfilesView использует lazy grid карточек с поиском и подтверждением удаления. SubscriptionView оформлен теми же карточками; сохранены безопасная загрузка, лимиты, revision и отмена запросов. DiagnosticsView содержит отдельные карточки физического IP, IP туннеля, Google и YouTube. Settings, Logs и legacy CAPTCHA имеют общие заголовки/пустые состояния. Современная CAPTCHA остаётся официальным внешним SDK.

## Адаптация

- Компактная ширина: системные вкладки и один столбец. Regular: sidebar и сетки карточек. Главная использует текущий размер контейнера, а не модель устройства.
- Accessibility Dynamic Type сворачивает сетки в один столбец. Высота текста не ограничивается; используются системные шрифты, семантические Button/Label и подписи accessibility. Декоративные изображения скрыты от VoiceOver.
- Главная не имеет фиксированной ширины орбиты: ограничен только максимум. Прокручиваемые страницы сохраняют доступ к действиям при узком окне и большом тексте.
- Светлый и тёмный режимы следуют системе. Нажатия используют короткую spring-анимацию; busy-кольцо вращается только на активной сцене. Reduce Motion отключает scale/вращение; в простое нет бесконечных анимаций. Переходы экранов выполняет NavigationStack.

## Статус проверки

Только исходники: static project guards, синтаксический parser46Swiftфайлов и проверка native mirror57файлов. Никакой сборки iOS, Swift type checking, XCTest, симулятора или устройств. SF Symbols, доступность API, контраст в реальных темах, VoiceOver, keyboard/safe areas, Split View, поворот и производительность требуют отдельной проверки на Mac/устройствах. Android TV не подтверждает эти свойства iOS.

Исторические Swift-редакторы исключённых старых flows не являются новой основной навигацией. Native framework, серверные протоколы и entitlement-контракт этой UI-работой не менялись.
